默认单线推进，不再组织多个“成员”并行开工。需要独立核对或后台跑批时，可以派子进程（subagent），但不要维护多线协作与来回派单。

**Why:** 用户明确说“团队已经解散，现在我们不搞多线并行了，效率反而低”；此前多成员派单与催办产生大量往返。

**How to apply:** 接到任务后自己按顺序做完；只把可独立验证的环节交给子进程；不要创建虚拟团队成员或并行任务链。
