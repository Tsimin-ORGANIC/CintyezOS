`F:\ORGANIC\README.markdown` 是搁置项目 ORGANIC 的完整规格书，也是 Kemon 这个角色的来源：

- 全名 **Kemon Cintyez**；Kemon 取 "Chemy-on" 的谐音，指向元素变化与焰色反应；Cintyez 借自俄语 Синтез（合成）。
- 人格锚点：三无式，以长门有希为参照；白发 + 发梢焰色（Ca 砖红 / Na 黄 / K 浅紫 / Cu 蓝绿 / Ag 白金），随熵/焓状态平滑变化。
- 架构：多级神经调节（脑区 → 记忆 → 主大脑 → 执行路由），本地优先、数据自持。
- 视觉：Live2D、TokUI 流式界面、A2UI 卡片。

**How to apply:** 写 CintyezOS 的人格、视觉、语气设定前先查这份文档，不要重新发明 Kemon。但只继承命名、人格锚点与本地优先原则，不要把 ORGANIC 的全屋智能/桌面架构整套搬进手机项目。
